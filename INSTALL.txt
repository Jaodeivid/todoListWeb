================================================================================
                    GUÍA DE INSTALACIÓN - TODOLIST WEB
================================================================================

REQUISITOS PREVIOS:
- Node.js 14+ (https://nodejs.org/)
- npm (viene con Node.js)
- MongoDB 4.4+ (local o en Atlas)
- Git
- mkcert (para certificados SSL)

================================================================================
PASO 1: CLONAR EL REPOSITORIO
================================================================================

git clone https://github.com/Jaodeivid/todoListWeb.git
cd todoListWeb

================================================================================
PASO 2: CONFIGURAR VARIABLES DE ENTORNO (.env)
================================================================================

2.1) Navega a la carpeta backend:
     cd backend

2.2) Copia el archivo .env.example a .env:
     Windows:  copy .env.example .env
     Mac/Linux: cp .env.example .env

2.3) Abre el archivo .env en un editor de texto y completa los valores:

PORT=3000

MONGODB=mongodb://localhost:27017/todolistweb
(O si usas MongoDB Atlas: mongodb+srv://usuario:password@cluster.mongodb.net/todolistweb)

JWT_SECRET=TuClaveSeguraDeAlMenosUnos32Caracteres123456

================================================================================
PASO 3: INSTALAR MONGODB (si no lo tienes)
================================================================================

OPCIÓN A - MONGODB LOCAL (Windows):
1. Descarga desde https://www.mongodb.com/try/download/community
2. Ejecuta el instalador
3. Sigue las instrucciones (se instalará como servicio)
4. Verifica que está corriendo: mongosh o mongo en terminal

OPCIÓN B - MONGODB ATLAS (Cloud - Recomendado):
1. Ve a https://www.mongodb.com/cloud/atlas
2. Crea una cuenta gratuita
3. Crea un cluster
4. Crea usuario y contraseña
5. Copia la cadena de conexión en MONGODB del .env

================================================================================
PASO 4: GENERAR CERTIFICADOS SSL (SOLO para el BACKEND)
================================================================================

IMPORTANTE: Solo el BACKEND necesita certificados HTTPS.
El Frontend React corre en HTTP, eso es NORMAL en desarrollo local.

INSTALACION MKCERT:

Windows (con Chocolatey):
  choco install mkcert -y

Windows (sin Chocolatey):
  1. Descarga https://github.com/FiloSottile/mkcert/releases
  2. Descomprime en el PATH

Mac:
  brew install mkcert

Linux:
  sudo apt install mkcert

GENERAR CERTIFICADOS:

1. Abre terminal/PowerShell en la carpeta backend/

2. Ejecuta:
   mkcert localhost

3. Renombra los archivos generados:
   Windows:   ren localhost.pem cert.pem & ren localhost-key.pem key.pem
   Mac/Linux: mv localhost.pem cert.pem && mv localhost-key.pem key.pem

Ahora tendrás: cert.pem y key.pem en la carpeta backend/

================================================================================
PASO 5: INSTALAR DEPENDENCIAS
================================================================================

Terminal 1 - Backend:
  cd backend
  npm install

Terminal 2 - Frontend:
  cd frontend
  npm install

================================================================================

En la terminal del backend, ejecuta:
  npm run seed

Esto cargará:

================================================================================
PASO 7: INICIAR LA APLICACIÓN
================================================================================

Desde la RAÍZ del proyecto, ejecuta:

  npm run dev

Esto inicia backend y frontend simultáneamente usando 'concurrently':
  - Backend: https://localhost:3000 (con certificado SSL)
  - Frontend: http://localhost:3000 (HTTP es normal en desarrollo)
  - Frontend: http://localhost:3000 (se abrirá automáticamente)

Esperado:
  Conectado a MongoDB
  Servidor corriendo en https://localhost:3000
  Webpack compilando...
  Compilation successful

================================================================================
PASO 8: PROBAR LA APLICACIÓN
================================================================================

1. Abre http://localhost:3000 en tu navegador
2. Si ves advertencia de certificado, acepta (es normal en localhost)
3. Inicia sesión con las credenciales de prueba
4. ¡Prueba la aplicación!

================================================================================
SOLUCIÓN DE PROBLEMAS
================================================================================

ERROR: "Cannot find module 'dotenv'"
SOLUCIÓN: npm install en la carpeta backend

ERROR: "MONGODB connection failed"
SOLUCIÓN: 
  - Verifica que MongoDB está corriendo
  - Verifica la URL en .env es correcta
  - Si usas Atlas, verifica tu IP está en la whitelist

ERROR: "EADDRINUSE: address already in use :::3000"
SOLUCIÓN: 
  - Cambia PORT en .env a otro valor (3001, 3002, etc.)
  - O cierra lo que está usando el puerto 3000

ERROR: "Certificado no seguro / Certificate error"
SOLUCIÓN: 
  - Es normal en localhost
  - Hace clic en "Advanced" > "Proceed to localhost"
  - Funciona correctamente
